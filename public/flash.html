Kita-Board · auf das NOTE4C installieren

1 · Firmware installieren (am Computer)

  1. Den neuen NOTE4C mit einem USB-C-Datenkabel direkt an den Computer anschließen, untere Taste rechts 3 s halten (= Ein).
  2. Auf „Installieren“ klicken, das Gerät wählen (USB JTAG/serial debug unit bzw. USB-Serial/JTAG (COM…)) → Verbinden → Install.
  3. Warten bis „Installation complete“, dann die untere Taste rechts gedrückt halten, bis sich das Display ändert.
Bitte Chrome oder Edge auf einem Computer verwenden. Die Seite muss über https geöffnet sein.

Gerät nicht gefunden? Runde Taste vorne halten, kurz ins RESET-Loch links drücken, loslassen, erneut installieren.

2 · WLAN und Adresse eintragen (mit dem Handy)

  1. Mit dem WLAN TRMNL-… verbinden; die Seite öffnet sich (sonst http://192.168.4.1).
  2. Advanced → Custom Server → Yes, bei API Server eintragen:
    https://…
  3. Back to Wi-Fi → WLAN wählen → Passwort → Connect. Nach ca. 1 Minute erscheint das Tagesbild.

Das Bild wechselt jeden Morgen um 5 Uhr. OK-Taste kurz = sofort neu laden, 5 s halten = WLAN neu einrichten.
